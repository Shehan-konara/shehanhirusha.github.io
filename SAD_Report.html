Executive Summary

This formal System Analysis and Design (SAD) report presents the comprehensive analysis, requirements specification, modeling, architectural design, implementation, test execution, and deployment plan for an individual professional portfolio website. The project was executed following structured System Development Life Cycle (SDLC) principles and UI/UX design intelligence from the ui-ux-pro-max skill set.

Section 1: System Planning

1.1 Problem Statement

Undergraduate ICT students often struggle to present their technical competencies, academic projects, and software design skills effectively to potential employers. Static resumes fail to showcase interactive web prototypes, UML modeling artifacts, system architecture designs, and live code repositories.

1.2 System Objectives

  • Primary Objective: Design, develop, test, and publish an interactive, mobile-responsive portfolio web application showcasing academic background, technical skills, project case studies, and SAD deliverables.
  • Secondary Objectives: Provide an online-viewable PDF CV, interactive project detail modals, client-side contact validation, and career-sharing evidence via LinkedIn.

1.3 Stakeholders & Constraints

Target stakeholders include recruiters, academic evaluators (lecturers), peer developers, and the system owner. Constraints include a 2-3 week timeframe and client-side static web deployment on GitHub Pages.

Section 4: System Design

4.1 Interface Design Decisions

  • Style Category: Cinema Dark Aurora Glassmorphism.
  • Typography: Space Grotesk (Headings), Archivo (Body), JetBrains Mono (Code/Badges).
